# 🚚 Logistics SLA & Delivery Performance Analytics

## 📌 Project Overview
An end-to-end Data Analytics project to analyze logistics delivery performance, SLA compliance, delivery delays, and operational costs.

## 🛠️ Tools & Technologies
- Python
- Pandas and NumPy
- SQL
- Power BI
- Jupyter Notebook

## 📊 Key Analysis
- Delivery Status Distribution
- SLA Compliance by Delivery Partner
- Average Delivery Cost by Region
- Average Delivery Cost by Vehicle Type
- Delivery Delay Rate by Weather Condition
- Delivery Mode Performance

## 💡 Business Insights
- Delivery delay rates vary across weather conditions.
- SLA compliance differs across delivery partners.
- Average delivery costs vary by region and vehicle type.
- Delivery mode performance should be reviewed to identify operational issues.

## 🎯 Recommendations
- Review delivery schedules during adverse weather.
- Investigate low-SLA delivery partners.
- Compare regional and vehicle-related costs.
- Validate unusual delivery performance patterns.
- Analyze failed deliveries to identify improvement opportunities.

## 📁 Project Files
- `Delivery_Logistics.csv` — Original dataset
- `Delivery_Logistics_Cleaned.csv` — Cleaned dataset
- `Logistics_Analysis.ipynb` — Python analysis
- `SQL Business Insights.sql` — SQL business queries
- `Dashboard sla.pbix` — Power BI dashboard
